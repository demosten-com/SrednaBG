# Vendored map-asset provenance & licenses

These files are the **static** half of the offline map bundle. Only the vector
tiles (`bulgaria.mbtiles`) change between map updates; the style and glyphs are
captured here once so `build-map-bundle.sh` can assemble a bundle with no tile
server and no network fetch of style assets.

## `style-template.json`

OpenMapTiles **"Basic preview"** GL style (the `basic-preview` demo style), with
its vector source / glyphs URLs replaced by the `{MBTILES_URI}` / `{GLYPHS_URI}`
runtime placeholders.

- Source: https://github.com/openmaptiles/maptiler-basic-gl-style
- License: **BSD-3-Clause** (code) + **CC-BY 4.0** (visual design).
- Attribution: must visibly credit **OpenMapTiles.org** (https://openmaptiles.org/).
  This is carried in the style's `sources.openmaptiles.attribution` field
  (© OpenMapTiles, © OpenStreetMap contributors) and rendered by MapLibre.

## `fonts/Noto Sans Regular/*.pbf`

Pre-rendered SDF glyph ranges for the single fontstack the style references.

- Font: **Noto Sans**, licensed under the **SIL Open Font License 1.1 (OFL)**.
- The `.pbf` glyph ranges are derivative encodings of the font and are equally
  redistributable under OFL. The OFL permits embedding/bundling.

## `bulgaria.mbtiles` (regenerated, NOT vendored here)

Generated by Planetiler from an OpenStreetMap extract at build time.

- Map data: **OpenStreetMap, ODbL**.
- Schema: **OpenMapTiles, CC-BY 4.0**.
- Both are credited via the style `attribution` above.
